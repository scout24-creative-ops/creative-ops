# Marketing Content Platform — retired alias

## Status

This is no longer an active project in Dominik's working model.

The former `Marketing Content Platform` label mixed several closely related but operationally different topics and created unnecessary ambiguity. Current work is maintained under two canonical projects:

- [Landing Page Builder](landing-page-builder.md) — the Builder product itself, including the Contentful-enabled GPT, Actions, module/runtime architecture, lifecycle support, Contentful integration and other Builder capabilities.
- [Contentful Migration](contentful-migration.md) — the actual migration of Marketing pages from AEM to Contentful using the Landing Page Builder, including migration scope, QA/handoff, assets, routing-related migration work and migration dependencies such as the B2B contact form.

Persistent asset storage that exists specifically to support the AEM-to-Contentful migration belongs to `Contentful Migration` unless a broader Marketing Asset Library / SSOT initiative is explicitly established as its own project later.

Do not create new tasks or current-status updates under `Marketing Content Platform`.

## Historical note

This file is retained only to preserve the old project name and prevent older references from being mistaken for a third active project. Relevant current context has been consolidated into the two canonical project files above.

## Last Confirmed

2026-09-07: Dominik retired `Marketing Content Platform` as an active project name and confirmed the two-project model of `Landing Page Builder` plus `Contentful Migration`.
