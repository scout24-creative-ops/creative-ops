# Projekte

Für jedes aktive Projekt wird ein eigener Ordner angelegt:

```text
projects/<projektname>/
├── overview.md
├── current-state.md
├── decisions.md
└── open-items.md
```

## Bedeutung
- `overview.md`: Ziel, Umfang, Beteiligte und Hintergrund
- `current-state.md`: aktueller Arbeitsstand und relevante Details
- `decisions.md`: gültige Projektentscheidungen mit kurzer Begründung
- `open-items.md`: offene Punkte, Verantwortliche und nächste Schritte
