# Weekly Summaries

Each calendar week has at most one concise, management-ready summary. Use the filename format `YYYY-Www.md`, for example `2026-W30.md`.

Create a weekly summary only when there are reportable developments for that week. Base it on confirmed new updates and the current Creative Operations summary; it is not a complete source of truth. Transfer long-term relevant information to [Creative Operations Summary](../../context/creative-operations-summary.md).

## Suggested Structure

```markdown
# Weekly Summary — YYYY-Www

_Period: YYYY-MM-DD to YYYY-MM-DD_

## Highlights

## Project Updates

## Decisions

## Risks and Blockers

## Next Week
```
